# 课件大纲 · JSON 使用教程

> 适用：Rev TechingMaster（鸿蒙 / 安卓版）「备课助手 → 课件大纲」
> 说明：本功能从 v2.x 起将生成内容严格限定为 **JSON 格式**，并支持一键导出 `.json` 文件，便于在其它课件工具或程序中二次使用。

---

## 1. 功能简介

「课件大纲」为教师的每节课自动生成**逐页课件大纲**（含页面类型、标题、讲解要点、配图方向），AI 输出**严格 JSON 数组**，而非普通文本。相比"复制成 Word 再排版"，JSON 可直接被课件工具、脚本、课堂演示程序识别，实现"大纲 → 课件"的流水线复用。

## 2. 操作步骤

1. 打开 App → 「备课助手」页签 → 点击「课件大纲」卡片。
2. 填写学科、年级、课题（必填）、课型/用途，可按需填写备注。
3. 点击橙色「生成课件大纲」按钮，等待生成（约 10~40 秒，页面实时滚动显示）。
4. 生成完成后，App 会自动校验并格式化 JSON；若模型偶发输出不纯 JSON，会提示"课件大纲不是有效 JSON，请重新生成"。
5. 结果区提供四个操作：
   - **编辑**：整屏查看/修改 JSON（修改后点"完成"回写）。
   - **复制**：把完整 JSON 复制到剪贴板。
   - **导出JSON**：弹出系统保存位置，存为 `.json` 文件（默认文件名：课件大纲-{课题}.json）。此为**课件大纲的默认导出格式**，不再导出 Word。
   - **保存到历史**：存入"历史记录"，可在历史页随时查看/复制/导出。

## 3. JSON 结构说明

生成结果是一个数组，数组含 **8~14 个页对象**，每个对象字段固定：

| 字段 | 类型 | 说明 | 取值示例 |
| --- | --- | --- | --- |
| `page` | 数字 | 页码（从 1 开始递增） | `1` |
| `type` | 字符串 | 页面类型（下述 7 种之一） | `"封面"` |
| `title` | 字符串 | 页面标题（≤18 字） | `"光的反射定律"` |
| `points` | 字符串数组 | 本页讲解要点（2~4 条，每条 ≤20 字） | `["反射角等于入射角", "法线是作图关键"]` |
| `visual` | 字符串 | 配图方向建议（≤20 字） | `"光线反射路径示意图"` |

**页面类型（type）与顺序约定：**

```
封面 → 导入 → 讲解(3~5 页) → 例题 → 练习 → 小结 → 作业
```

`type` 取值固定为：`封面 / 导入 / 讲解 / 例题 / 练习 / 小结 / 作业`。

**示例（片段）：**

```json
[
  {
    "page": 1,
    "type": "封面",
    "title": "光的反射",
    "points": ["苏科版八年级物理", "认识光的反射现象"],
    "visual": "平面镜与入射光线场景图"
  },
  {
    "page": 4,
    "type": "讲解",
    "title": "反射定律",
    "points": ["三线共面", "反射角等于入射角"],
    "visual": "入射角与反射角标注图"
  }
]
```

> 注：界面语言为英文/少数民族语言时，`title/points/visual/type` 等内容会按当前语言输出，但**字段键名（page/type/title/points/visual）始终保持英文不变**，保证程序可解析。

## 4. 导出文件的常见用法

- **课堂演示**：把 `.json` 交给支持 JSON 导入的课件/PPT 生成脚本，自动转为逐页幻灯片大纲。
- **二次加工**：用脚本（如 Python/Node）读取后，结合图片素材批量生成 PPT/网页课件，字段 `visual` 可直接作为配图提示词。
- **存档分享**：`.json` 体积小、结构清晰，便于提交教研材料或团队协作共享。

简易解析示例（JavaScript）：

```js
const outline = JSON.parse(fs.readFileSync('课件大纲-光的反射.json', 'utf8'));
outline.forEach((page) => {
  console.log(`第${page.page}页 [${page.type}] ${page.title}`);
  page.points.forEach((p) => console.log('  · ' + p));
});
```

## 5. 常见问题（FAQ）

**Q1：生成结果不是 JSON / 提示重新生成？**
模型偶发输出不满足严格 JSON。点击「重新生成」即可；若多次失败，可减少"备注"里的特殊要求或简化课题表述后重试。

**Q2：我编辑了 JSON，导出的是修改后的版本吗？**
是。进入「编辑」修改并点"完成"后，预览与导出均基于最新文本；导出时会再次做 JSON 合法性校验，合法则自动格式化缩进。

**Q3：其它功能的导出还是 Word 吗？**
是。仅「课件大纲」以 JSON 为主要产物；教案、分层练习、学情报告等功能仍导出 Word（便于直接排版使用）。

**Q4：导出的 JSON 能否用于本 App 其它页面？**
当前版本主要用于外部工具。App 内已提供"编辑/复制/历史"能力，可直接查看与复用。
